# Feature comandas

La pantalla del mesero opera el ciclo que le corresponde:

1. Abrir mesa y capturar productos por comensal.
2. Enviar el pedido a cocina.
3. Visualizar lotes listos liberados por cocina.
4. Confirmar entrega a la mesa por lote.
5. Enviar la cuenta completa al módulo independiente de Caja.

El mesero nunca captura importe pagado ni libera la mesa directamente.
