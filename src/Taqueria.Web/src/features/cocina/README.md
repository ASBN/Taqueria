# Feature cocina

La pantalla operativa se mantiene en `pages/CocinaPage.tsx` durante el MVP para facilitar lectura y depuración.

En version-003 permite:

- Consultar comandas enviadas a cocina.
- Separar órdenes pendientes y listas.
- Liberar cantidades parciales por partida.
- Visualizar el historial de cantidades liberadas.

La extracción a componentes o hooks compartidos se realizará únicamente cuando el flujo crezca y exista reutilización real.
